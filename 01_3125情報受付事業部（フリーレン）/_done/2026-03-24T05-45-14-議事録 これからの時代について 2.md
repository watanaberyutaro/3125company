# 📝 議事録: これからの時代について

## 文字起こしデータ
1. AI時代の労働とケインズの予測
直接生産的な仕事はロボットが、知的生産はAIが担うようになると、人間は人間同士の関係をいかに面白く、文化的な価値にするかということに時間を使うようになります
。経済学者ケインズは将来的に労働時間が減ると予測していましたが、実際には予測を上回る経済成長の一方で、労働時間はむしろ増えています
。
これまでの「働く」という概念は、江戸時代の「食べるため」、産業革命後の「工場生産のため」、そして近年の「知的システム（ホワイトカラー）を回すため」と変化してきました
。しかし、AIエージェントの登場により、表を埋めるようなホワイトカラーの仕事も終わりを迎えつつあります
。この150年ほどの労働の仕方は、歴史的に見ればむしろ異常な状態だったと言えます
。
2. 「軍事 × ライフ」と「人口減少」のメリット
現代は、「軍事」と「ライフ（暇つぶし）」の両極が並存する時代です
。
軍事： ドローンなどの無人兵器による自動化が進み、国防の再検討が全世界で起きています
。
ライフ： 働くための道具は溢れていますが、主体的に楽しむための道具はまだ不足しています
。今後は、アニメやスポーツのように、フィジカル・デジタルの両面で「暇つぶし」の価値がどんどん上がっていきます
。
日本にとって、人口減少とAIによる自動化が同時に起きていることは、実は幸運なことです
。労働力が足りない中でAIが補ってくれるため、他国で懸念されるような「AIによる失業と内乱」のリスクが低く、社会を「筋肉質」にするチャンスと言えます
。
3. 「サバイブ」から「コバイブ」へ、そして「デジタル発酵」
これからの組織や生き方は、管理・制御を主とする「サバイブ（Survive）」から、共に生きる楽しさを追求する**「コバイブ（小バイブ/Covive）」**へと変化します
。
デジタル発酵： AIエージェントが微生物のように勝手に働き続ける状態を「デジタル発酵」と呼びます
。人間はそれを個別に制御することはできません
。
調立者としての人間： 人間は管理職（マネージャー）ではなく、環境を設計し、場の空気を整える**「調立者」**になる必要があります
。
レコード針のような感性： 良いリーダーとは、世界の「味」や「場の変化」を敏感に察知できる**「レコード針」のような認識能力とセンス**を持つ人です
。
4. 「ホモ・サピエンス」から「ホモ・コンビーム」へ
AIが文明のドライバー（発展の担い手）になることで、人間は「賢い人」という意味の「ホモ・サピエンス」である必要がなくなります（さよならホモ・サピエンス）
。
これからの人間は、共に楽しむことを本質とする**「ホモ・コンビーム（Homo Convivium）」**へと移行します
。
人間には意義も意味もない： サピエンスとしての役割がAIに移るため、人間そのものに先験的な意味はありません
。
意味を作るのは「祭り」： 意味は考えるものではなく、祭りのように「何かを一緒に行うこと」で後から生まれるものです
。
5. 最も大切なのは「ご縁」
超AI時代において、人間に残る最も重要な要素は**「ご縁」**です
。 ビジネス的な「人脈」とは異なり、同じ時間を楽しく過ごし、お互いの歴史に刻み込んでいくような、緩やかで双方的な関係性が価値を持ちます
。
良い「ご縁」に恵まれるためには、世界との対話回数を増やし、移動距離を広げ、不思議なことや面白いことに積極的に触れることが大切です
。労働力としての価値がなくなる中で、「楽しめる人」「面白がれる人」になることが、これからの時代の生き方となります
