## 1. 現状の問題

`stream.js` の処理フローを確認した結果、雑談に相当するメッセージは現在すべて **キューに積まれてしまっている**。

```
ユーザー「ねえ、ちょっと愚痴があって」
  → isCalendarAdd: false
  → isCalendarRead: false
  → isTaskRead: false
  → isInstant: false
  → classifyTask() → { type: "general", dept: "秘書室" }
  → _pending/ に保存
  → 「秘書室に頼んでおいたわ」（終了）← ❌ 会話にならない
```

Claude APIは一切呼ばれず、フリーレンが話し相手にならない。

---

## 2. 設計方針

### フェーズ1（今回実装）: 案B - 冒頭キーワード判定

`stream.js` の `runAgentStream()` に `isChitchat` 判定を追加。
キーワードに合致したメッセージは **キューに積まず、即座にClaude API（Haiku）で応答** する。

- ツール使用なし（保存・カレンダー登録・Web検索なし）
- 会話履歴（history）と owner-profile を参照 → 文脈のある返答（案Cの要素も同時に実現）
- Haikuモデルを使用（コスト: Sonnetの約1/5）
- 応答後は会話履歴に保存（appendHistory）・プロフィール更新（updateProfile）

### フェーズ2（将来）: 案A - UIトグルボタン

`index.html` に「💬 雑談」チップを追加。ONの間はすべてのメッセージを雑談扱い。
