# 2026-04-06 朝のニュース

## AI・テクノロジー

### Anthropic、Claude サブスクリプションでの外部AIエージェント利用を禁止

AnthropicはClaude ProおよびMaxサブスクリプションユーザーが、サードパーティ製AIエージェントフレームワーク（OpenClawなど）を通じてClaudeを利用することを2026年4月4日付で突然終了しました。該当ユーザーは従量課金制（API課金）への移行を求められています。開発者コミュニティでは「月額定額でAIエージェントを自由に使える時代が終わる」という声が上がっています。

- 出典: [BigGo ニュース](https://biggo.jp/news/202604050055_Anthropic-Claude-blocks-third-party-AI-agents-subscription) / [GPT Master](https://chatgpt-enterprise.jp/blog/anthropic-claude-subscription-third-party-ban/)
- **示唆**: 当社のAI導入支援事業では、APIを通じた従量課金モデルを前提とした設計を推奨する必要があります。サブスクリプション前提でのエージェント構築は顧客に追加コストリスクを生じさせる可能性があります。

### OpenAI、GPT-5.4シリーズを展開中

OpenAIはGPT-5シリーズの継続的な進化を続けており、GPT-5.4（フロンティアモデル）、GPT-5.4 mini・nano（軽量モデル）をリリースしています。GPT-5.4は44職種にわたる知識労働でアメリカの業界プロフェッショナルの83.0%と同等またはそれを上回る性能を示しており、GPT-5.2時点の70.9%から大幅に向上しています。

- 出典: [OpenAI 公式](https://openai.com/gpt-5/) / [Qiita - OpenAI最新モデル動向2026](https://qiita.com/AI-SKILL-LAB/items/a0a6463042713a1e85cc)
- **示唆**: GPT-5.4の知識労働代替率が83%に達したことは、AI導入支援事業において「どの業務にAIを使うか」の提案の幅が広がったことを意味します。顧客への提案力強化につながります。

### AnthropicがOpenAIのClaude APIアクセスを制限

AnthropicがOpenAIによるClaude APIへのアクセスを制限したとの報道があります。両社の競争が激化しており、法人向け市場ではAnthropicの法人顧客シェアが80%、OpenAIが40%と、Anthropicが優位に立っています。新規導入企業間でのAnthropicの選択率はOpenAIの3倍とも報じられています。

- 出典: [TradingKey 分析](https://www.tradingkey.com/jp/analysis/stocks/us-stocks/261741917-openai-ipo-claudecode-anthropic-tradingkey)
- **示唆**: 法人向けAI市場でClaudeが優位という状況は、当社のAI導入支援においてClaudeを主軸とした提案を強化するチャンスです。

### Code with Claude 東京 2026（6月10日開催予定）

AnthropicによるAI開発者向けカンファレンス「Code with Claude 東京 2026」が2026年6月10日に東京で開催される予定です。日本のClaude利用は開発者中心であることがMicrosoftイベントでのAnthropic登壇でも語られました。

- 出典: [AI Career Japan](https://ai-career-japan.jp/posts/code-with-claude%E6%9D%B1%E4%BA%AC2026%E5%AE%8C%E5%85%A8%E3%82%AC%E3%82%A4%E3%83%89/) / [Impress Watch](https://www.watch.impress.co.jp/docs/news/2096124.html)
- **示唆**: 6月10日のカンファレンスは参加を検討する価値があります。開発者・顧客向けの最新情報収集およびネットワーキングの機会となります。

## ビジネス・経済

### トランプ関税が日本経済に波状的な打撃

2026年4月、トランプ政権による対日相互関税（15%）および自動車・部品への追加関税（25%）が発動されています。電気・ガス料金の政府補助も2026年3月末で終了し、4月以降は電気代で月700〜1,500円、ガス代で月300〜500円の値上がりが見込まれています。

- 出典: [日本経済新聞 - トランプ関税](https://www.nikkei.com/topics/25021100) / [ジェトロ](https://www.jetro.go.jp/world/us_tariff/)
- **示唆**: 顧客企業のコスト環境が悪化しており、「コスト削減・業務効率化」を切り口にしたAI導入提案の訴求力が高まっています。

### 食品2,278品目が一斉値上げ・企業コスト環境の悪化

2026年4月は食品2,278品目が値上げ。原材料価格の高騰と円安の影響が続いており、企業全体のコスト圧力が強まっています。日経平均株価は4月4日に前週末比249円安の53,123円で反落しました。

- 出典: [jyouhounomori.com - 2026年4月から変わること](https://jyouhounomori.com/2026/03/23/april-2026-changes-list/) / [BTCC](https://www.btcc.com/ja-JP/square/minkabuJP/1614653)
- **示唆**: 景況感の悪化局面では、明確なROIを提示できるAI・システム導入提案が刺さりやすくなります。投資対効果の数値化を提案書に盛り込む戦略が有効です。

### 令和8年経済センサス-活動調査 開始

経済産業省が2026年4月1日より「令和8年経済センサス-活動調査」を全国の事業者を対象に開始しました。日本経済の実態把握に向けた動きです。

- 出典: [経済産業省](https://www.meti.go.jp/press/)
- **示唆**: 統計データが公開された際には、AI事業・システム開発事業の市場規模把握に活用できます。

## スマートフォン・通信

### NTTドコモ FOMA・iモード 2026年3月31日終了 — 4月以降は4G/5G移行必須

NTTドコモは第3世代通信方式FOMAおよびiモードを2026年3月31日に終了しました。4月以降はFOMA契約が自動解約となり、継続利用には4G/5G端末への移行が必要です。

- 出典: [DXマガジン](https://dxmagazine.jp/news/2611to30/) / [ITmedia NEWS](https://www.itmedia.co.jp/news/articles/2602/09/news097.html)
- **示唆**: スマホセールスプロモーション事業・スマホショップコンサル事業において、3G終了に伴う買い替え需要・プラン変更需要の取り込みが引き続きチャンスです。現場スタッフへの対応トレーニングの提案余地があります。

### ドコモ・au・ソフトバンクが衛星直接通信サービスを展開

KDDIがSpaceXのStarlinkを活用したスマホと衛星の直接通信サービスをすでに開始。NTTドコモも2026年度初頭（4月〜）に同様のサービスを開始予定。ソフトバンクも2026年内の開始を表明しています。

- 出典: [ITmedia NEWS](https://www.itmedia.co.jp/news/articles/2602/09/news097.html) / [UchuBiz](https://uchubiz.com/article/new61297/) / [日本経済新聞](https://www.nikkei.com/article/DGXZQOUC093BT0Z00C26A2000000/)
- **示唆**: 衛星通信は山間部・海上など従来の電波圏外エリアをカバーします。スマホショップコンサル事業での訴求ポイントとして活用できます。また、当社のAI・システム開発事業でも衛星通信インフラを前提にしたソリューション提案の可能性があります。

### ソフトバンク、5G人口カバー率96%突破

ソフトバンクが5Gの人口カバー率96%を達成したと発表。キャリア間の通信品質競争は引き続き激化しています。2026年の通信品質評判ではauが最上位との評価があります。

- 出典: [ロケホン](https://rokemoba.com/smartphone/docomo-au-softbank-doregaii/) / [シムコネクト](https://sim-connect.jp/3career/)
- **示唆**: スマホショップコンサル事業では、各キャリアの最新カバレッジ・品質データを販売員が把握していることが差別化に直結します。定期的な勉強会・情報共有の仕組みを提案できます。

### 気づいたこと・注目点

- **AnthropicのAPIポリシー変更は要注意です**。当社がClaude APIを活用したシステム開発・AI導入支援を展開している場合、サブスクリプション経由でのエージェント利用はリスクになります。顧客にはAPI（従量課金）前提の設計を推奨することをお勧めします。
- **GPT-5.4の知識労働代替率83%**は、AI導入支援事業における提案の幅が大幅に広がったことを示します。「どの業務を自動化できるか」の具体的な提案書の更新が必要です。
- **3G終了後の買い替え需要**は4月以降も続きます。スマホ販促・ショップコンサル事業でのタイムリーな動きが重要です。
- **トランプ関税によるコスト環境の悪化**は、逆説的にAI・効率化ツールへの需要を高めます。「コスト削減」切り口での提案強化を推奨します。
- **Code with Claude 東京 2026（6月10日）**への参加を検討してください。Anthropicとのネットワーキングおよび最新動向の把握に有効です。
