```dataviewjs
dv.el("div", [
  `- [[タスクダッシュボード]]`,

  `- [[01_3125情報受付事業部（フリーレン）/3125 朝礼（フリーレン）/${today}|今日のブリーフィング]]`,
  `- [[全情報まとめ]]`,
].join("\n"));
```

## 01_3125情報受付事業部（フリーレン）

```dataview
TABLE file.mtime as "更新日", file.folder as "フォルダ"
FROM "01_3125情報受付事業部（フリーレン）"
WHERE file.name != "_template.md"
SORT file.mtime DESC
LIMIT 10
```
