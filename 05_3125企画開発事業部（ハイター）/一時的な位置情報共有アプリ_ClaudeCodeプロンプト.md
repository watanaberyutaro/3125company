# 一時的な位置情報共有アプリ — Claude Code プロンプト

## 概要
待ち合わせ専用の一時的な位置情報共有アプリ。リンク発行→共有→完了で自動削除。

---

## Claude Code 実装プロンプト

```
以下の仕様で「一時的な位置情報共有アプリ」を実装してください。

## アプリ概要
- 待ち合わせ専用の一時的な位置情報共有アプリ
- ホストがリンクを発行 → ゲストがリンクを開く → 双方の位置をリアルタイム表示 → 完了ボタンで位置情報削除

## 技術スタック
- Frontend: React (Next.js) + TypeScript
- Backend: Node.js (Next.js API Routes or Express)
- リアルタイム通信: Socket.io
- DB: Redis（揮発性データ、TTL付き）
- 地図: Google Maps API または Mapbox GL JS
- デプロイ: Vercel or Railway

## 機能要件

### F-01 リンク発行
- ホームページに「待ち合わせを始める」ボタン
- ボタン押下でユニークなセッションID（UUID）を生成
- 共有URL例: https://example.com/meet/[sessionId]
- URLをコピー or LINEシェアボタン

### F-02 位置情報共有
- ホスト・ゲスト双方がブラウザのGeolocation APIで現在地を取得
- WebSocket（Socket.io）でリアルタイム送受信
- Google Maps or Mapbox上に2者のピンを表示
- 相手との距離をメートル表示

### F-03 完了操作
- 「完了」ボタン押下でセッション終了
- 位置情報の送信停止
- Redis上のセッションデータを即時削除
- 「待ち合わせ完了！位置情報を削除しました」画面に遷移

### F-04 自動失効
- セッション作成から6時間でRedisのTTL切れ → 自動無効化
- 期限切れURLアクセス時は「このリンクは有効期限切れです」と表示

### F-05 無登録利用
- アカウント登録不要
- セッションIDとトークン（JWT or HMAC）のみで認証

## 非機能要件
- HTTPS必須（Geolocation APIの要件）
- 完了後はサーバー上の位置データを即時削除（プライバシー優先）
- モバイルファーストのレスポンシブデザイン
- iOS Safariでのバックグラウンド位置情報制限に対応（フォアグラウンド前提で設計）

## 画面構成
1. /        → ホーム（リンク生成ボタン）
2. /meet/[id] → マップ画面（双方の現在地 + 完了ボタン）
3. /done    → 終了画面（削除完了メッセージ）
4. /expired → 期限切れ画面

## セキュリティ
- セッションIDはUUID v4
- アクセストークンをURLクエリパラメータに付与してなりすまし防止
- Redis保存データは位置情報のみ（個人情報は保存しない）

## 実装手順
1. Next.jsプロジェクト作成 (TypeScript)
2. Redis接続設定（ioredis）
3. Socket.ioサーバー設定
4. セッション生成APIの実装
5. Geolocation + Socket.io クライアント実装
6. Google Maps / Mapbox 地図表示実装
7. 完了ボタン → データ削除フロー実装
8. UI/UXの仕上げ（モバイル対応）
9. Vercelデプロイ設定
```
