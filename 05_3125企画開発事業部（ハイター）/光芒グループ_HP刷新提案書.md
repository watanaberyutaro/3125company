## 2. 訴求軸（フランメ案）

**信頼 × 実績 × 採用力** の3軸

| 軸 | 訴求ポイント |
|---|---|
| 信頼 | 企業理念の可視化、スタッフ顔出しコンテンツ |
| 実績 | 数字で語る実績（稼働人数・取引社数・継続率） |
| 採用力 | 求職者UX向上、スタッフの声（UGC活用） |

**トンマナ**：紫 → 紺×白でプロ感を底上げ

---

## 3. 技術構成案

### 推奨スタック

| 項目 | 推奨 | 理由 |
|---|---|---|
| CMS | WordPress + Elementor Pro | 現行からの移行コスト最小、クライアント更新容易 |
| ホスティング | さくらインターネット or Xserver | 国内安定、コスパ良好 |
| SSL | 無料（Let's Encrypt） | 標準装備 |
| フォーム | Contact Form 7 | 採用応募・問合せ両対応 |
| SEO | Yoast SEO | 人材系キーワード対策 |
| 分析 | Google Analytics 4 + Search Console | 採用流入改善のため必須 |

### ページ構成（推奨）

```
TOP
├── 会社概要
├── 事業内容（販売接客 / テレマーケティング / 運送）
├── 実績・数字で見る光芒
├── スタッフの声
├── 採用情報
│   ├── 求人一覧
│   └── 応募フォーム
└── お問い合わせ
```

## 5. 差別化ポイント

1. **スタッフの顔が見える設計**：顔写真＋インタビュー形式で信頼感を醸成
2. **採用側・求職者両軸のUX**：企業向けと求職者向けで導線を分離
3. **数字コンテンツ**：「稼働スタッフ〇〇名」など実績を視覚化
4. **SNS連携**：求職者向けInstagram等との連携導線
