### 1-3. 経済サイクル（4フェーズ）

| フェーズ | 継続期間 | 主なトリガー | 主な効果 |
|---------|---------|------------|---------|
| 好況 | 6〜18ヶ月 | 大型貿易条約・豊作・新技術解放 | 交易量+20%・国庫収入+15%・NPC幸福度+10 |
| 過熱 | 3〜6ヶ月 | 好況の長期継続・投機的取引増加 | 物価+15%・交易リスク+10%（放置でバブル崩壊） |
| 不況 | 6〜12ヶ月 | 自然災害・戦争・バブル崩壊・疫病 | 交易量-20%・国庫収入-15%・失業率+10% |
| 回復 | 4〜8ヶ月 | 不況終了後自動・政策介入・外部支援 | 交易量+5%・徐々に好況へ遷移 |

**現在のフェーズ:** 好況

#### 安定化政策

| 政策 | 効果 | 必要条件 |
|------|------|---------|
| 中央銀行介入 | 過熱・不況を1フェーズ短縮 | tech: com_5 |
| 国際支援協定 | 不況中の他国支援で関係値+15 | — |
| 緊急関税 | 輸入超過による国庫流出を一時抑制 | — （外交摩擦リスクあり） |

#### GDP計算式

```
GDP = 国庫初期値 + 税収 + 交易利益 + クエスト報酬 - 軍事費 - 行政費 - 輸入コスト
```

- 国庫が **50万El以下** → 「財政危機」フラグ発生
- 国庫が **1万El以下** → 国家崩壊リスク（他国支援により実際の崩壊は極めて稀）

## 3. 技術開発ツリー

### 学習ルール

| ルール | 内容 |
|--------|------|
| 自律習得 | NPCは自分の職業・興味・関係値に基づき自律的に技術を習得する。強制的な割り当てはしない |
| 興味駆動 | スキル値が高いカテゴリを中心に研究が進む（研究値80以上のNPCは分析系技術を自然に追求） |
| 国際伝播 | 交流イベント・貿易・移民を通じて技術が他国に伝播。伝播には関係値30以上が必要 |
| ブレークスルー | 同分野の技術を2つ以上習得した国で確率的に発生 |
| 公式化 | NPCの個人研究が国の公式技術になるには族長・総督・塔長の承認が必要 |
