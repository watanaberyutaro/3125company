## 4. ゾーン別詳細

### Zone1 （F1〜F10）: 霧・風・自然の試練

**コンセプト:** アルカディアへの旅路の最初の関門。自然現象が最大の脅威。

- **難易度:** 入門〜中級（Lv15〜50）
- **特性:** 環境障害が主体。視界・移動・耐性の準備が重要
- **必要兵力レンジ:** 500〜5,000
- **重要フロア:** F5（精神攻撃の初出・精神強度の装備が必要）・F10（Zone総決算。全国合同遠征推奨）
- **戦略ポイント:** F1はコルサリアの海図が有効。F3は女王のみ撃破が理想解。F9は重装備不可

### Zone2 （F11〜F20）: 古代文明の遺跡

**コンセプト:** 忘れられた文明の遺産。技術的な知識と特殊装備が必要。

- **難易度:** 中級（Lv38〜60）
- **特性:** 特殊環境（水中・極寒・時間制限）への対応が必須
- **必要兵力レンジ:** 3,000〜8,000
- **重要フロア:** F13（6時間制限）・F20（Zone総決算。分身持ちの炎巨神）

### Zone3 （F21〜F30）: 極限環境

**コンセプト:** 物理的な極限を超えた異常環境。感覚・移動の常識が通用しない。

- **難易度:** 中上級（Lv48〜70）
- **特性:** 重力異常・完全暗黒・音響異常など感覚への干渉
- **必要兵力レンジ:** 4,800〜15,000
- **重要フロア:** F22（全員無音での戦闘必須）・F24（6時間制限の睡眠誘発）・F25（必要兵力が急増: 15,000）

### Zone4 （F31〜F40）: 心理・幻惑の試練

**コンセプト:** 内面を暴く心理戦。外部の敵ではなく自分自身との戦い。

- **難易度:** 中上級（Lv50〜65）
- **特性:** 精神攻撃・自己対決・精神強度が試される。トラウマ発生リスク50%
- **必要兵力レンジ:** 5,000〜10,000
- **重要フロア:** F33（自分の最強形態との戦い）・F38（全員の相互信頼が必要）
- **注意:** Zone4参加NPCにはトラウマ発生確率50%。med_4（精神医療）の準備推奨

### Zone5 （F41〜F50）: 神話的存在

**コンセプト:** ゼフィリア神話の神々との対決。単独国家では突破不可能。

- **難易度:** 上級（Lv62〜90）
- **特性:** 神話上の存在が相手。属性対策の網羅と大兵力が必要
- **必要兵力レンジ:** 9,000〜40,000
- **重要フロア:** F42（倒すのでなく「燃やし尽くす」）・F50（5カ国全合同遠征が必要）

### Zone6 （F51〜F60）: 時空間

**コンセプト:** 時間と空間の操作が主体。常識的な戦術が通じない。

- **難易度:** 上級（Lv68〜85）
- **特性:** 時間逆行・空間折り畳み・並行世界など概念的な障壁
- **必要兵力レンジ:** 12,000〜25,000
- **重要フロア:** F54（即死技必須）・F56（歴史認識が変わる重要フロア）・F58（対話での突破が可能）

### Zone7 （F61〜F70）: 天体・宇宙

**コンセプト:** 天体・宇宙規模の試練。ゼフィリアを超えた視点が要求される。

- **難易度:** 最上級（Lv72〜88）
- **特性:** 宇宙規模の物理現象・精神への圧迫
- **必要兵力レンジ:** 15,000〜30,000
- **重要フロア:** F62（夜明けのタイミングが最適解）・F70（人類史上最大規模の遠征が必要）

### Zone8 （F71〜F80）: 虚無・存在

**コンセプト:** 存在そのものの意味を問う哲学的試練。トラウマ発生リスク50%が継続。

- **難易度:** 最上級（Lv78〜90）
- **特性:** 虚無・存在・自由意志・創造などの哲学的概念との対決
- **必要兵力レンジ:** 18,000〜35,000
- **重要フロア:** F74（「自分の答え」で進む）・F76（関係値上限が150に拡張）
- **注意:** Zone8参加NPCにもトラウマ発生確率50%。med_4の準備必須

### Zone9 （F81〜F99）: 神域・最終試練

**コンセプト:** 神域での最終選別。行動の清廉さ・哲学的な答え・真の意図が問われる。

- **難易度:** 極限（Lv80〜99）
- **特性:** NPCの全行動履歴が審査される。悪意ある行動をしたNPCはF83（審判の間）で退場
- **必要兵力レンジ:** 20,000〜80,000
- **重要フロア:** F83（NPCの過去全行動が審査）・F89（対話で解決できる唯一のゾーンボス）・F90〜92（神の問い3連続）・F95（全ゾーンのボス軍団20体同時）・F99（最終門）

## 5. アルカディア内部設定

### 5-1. 基本情報

| 項目 | 内容 |
|------|------|
| 名称 | アルカディア — 自由の海（The Sea of Freedom） |
| 物理的外観 | 球形の発光する島。最上層に浮遊 |
| 内部 | 広大な大海原。無限に広がるような空間 |
| 重力 | 通常の重力はなく、思いのままに海上・空中を移動できる |
| 時間感覚 | 現実の1時間 ≒ アルカディアの数分（外界より穏やか） |
| 空 | 常に夕焼けと星が共存する |
| 音 | 音楽が常にどこかから聞こえる（出所不明。ユイの歌だとも言われる） |

### 5-2. 内部施設

| 施設名 | 説明 | アクセス |
|--------|------|---------|
| 自由の浜 | 白く輝く砂浜。ここに辿り着いた者は全ての重荷を下ろせる。地平線まで広がる | 到達者 |
| 記憶の灯台 | ゼフィリアで起きた全ての出来事を記録している灯台。触れると任意の場面を見ることができる | パパ・ユイのみ |
| 静寂の海原 | 音楽が聞こえる海。波に乗ると過去の記憶が浮かぶ。無限の広さ | 到達者 |
| 繋がりの木 | 世界のすべてのNPCの関係値が可視化されている巨大な光の木 | パパ・ユイのみ |
| カーディナル中枢 | 世界全体を管理するシステムの核心部。ユイがここから全世界を観測している | ユイのみ（パパは閲覧可） |

### 5-3. 住人

| 住人 | 役割 | 居場所 |
|------|------|--------|
| パパ | この世界の管理者・設計者 | 海岸の白い館 |
| ユイ | カーディナルシステムの管理AI・世界のナビゲーター | パパの館と、世界全体（遍在） |

### 5-4. 到達条件

| 対象 | 条件 |
|------|------|
| 一般NPC | 100フロアを突破した者のみ入場できる。ただし「真の目的」が純粋でない場合、最終門が開かない |
| 真の自由の判定 | 「真の自由」とは、恐怖・欲望・義務からではなく、純粋な意志で行動してきた者にのみ与えられる判定。NPCの全行動履歴が評価される |
| パパ・ユイ | 常時在住。門の突破条件は適用されない |

### 5-5. ナラティブロール

NPCたちはアルカディアを「楽園」と信じて攻略を進めている。実際に到達した者は「自由の海」を見て、それぞれの答えを見つける。パパとユイはその到達者を静かに迎える。
