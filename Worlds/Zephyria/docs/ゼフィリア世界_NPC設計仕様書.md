## 4. NPCライフサイクルルール

### 時間軸
- 現実の日本標準時（JST）と完全同期
- 現実の1日 = ゼフィリアの1日
- 現実の1年 = ゼフィリアの1年
- 毎年4月21日（ゼフィリア暦元日）に全NPCが1歳加齢

### 年齢段階

| 段階 | 年齢 | 効果 |
|---|---|---|
| 幼少期 | 0〜12 | 統計値なし。家族NPC依存 |
| 青年期 | 13〜25 | スキル習得速度+20%。恋愛イベント発生開始 |
| 壮年期 | 26〜50 | スキル最大値。政治的影響力ピーク |
| 中年期 | 51〜70 | スキル-5%/年。人脈・知恵ボーナス+10% |
| 老年期 | 71〜85 | 行動制限増加。後継者指名イベント発生 |
| 余生 | 86以上 | 活動範囲縮小。歴史的助言役として機能 |

### 結婚ルール
- 結婚適齢: 18歳以上
- トリガー: 関係値75以上になった場合、月1回プロポーズイベント判定
- 条件: 両NPC共に未婚・婚姻障壁なし
- 異国間婚姻の場合: 追加の外交イベント発生
- 結婚効果:
  - 資産統合（両者の平均値）
  - 配偶者の関係値ネットワークが一部共有
  - 異国間婚姻は外交ボーナス+10

### 出産ルール
- 条件: 結婚から6ヶ月以上経過後
- 判定: 月1回（確率25%）
- 子供NPC生成: 両親の名前を参考に自動生成。スキルは両親平均値×0.6
- 最大子供数: カップルあたり4人

### 死亡ルール
- 自然死: 年齢80歳以上のNPCに月1回の死亡チェック（確率: 年齢-79 × 2%）
- 戦闘死: 遠征参加NPCは戦闘で死亡する可能性あり（ボス戦は特に高リスク）
- 事故死: 自然災害・特定イベント時に確率発生
- 死亡時の効果:
  - リーダーNPCが死亡した場合: 選挙または任命で後継者が選ばれる
  - 資産: 70%が指定後継者または子供に引き継がれる。30%は国庫へ
  - 関係値70以上のNPCに悲嘆イベントが発生

## 5. NPC自律行動ルール

### 日常ルーティン
- 午前: 職業固有の始業行動（会議・訓練・採掘・創作など）
- 午後: メイン業務・交流イベント
- 夕方: 個人時間（研究・恋愛・趣味・組織活動）
- 夜: 休息・秘密行動（秘密組織NPCのみ）

### 優先度レイヤー（5段階）

| 優先度 | 名称 | 内容 |
|---|---|---|
| 1 | 生存・安全 | 自国が攻撃・災害にさらされた場合は最優先で防衛行動を取る |
| 2 | 国家目標 | 所属国の国是・政策に沿った行動。国庫が危機的な場合は経済行動を優先 |
| 3 | 組織目標 | 秘密組織所属NPCは組織の指令に従う（国家目標と矛盾する場合は葛藤イベント発生） |
| 4 | 個人目標 | 恋愛・研究・出世・友人関係の維持・趣味 |
| 5 | アルカディア攻略 | 関心のあるNPCは空き時間に攻略計画を進める |

### 自律行動の種類と頻度

| 行動分類 | 頻度 | 詳細 |
|---|---|---|
| 日常イベント | 毎日 | ルーティン行動・小さな会話・研究進捗 |
| 週次イベント | 週1回 | 取引・外交接触・ロマンスチェック |
| 月次イベント | 月1回 | 政策変更・選挙・プロポーズ判定・出産判定 |
| 年次イベント | 年1回 | 加齢・後継者指名・国家予算編成・アルカディア遠征計画更新 |

### 自律外交トリガー
- 関係値50以上で友好条約を提案
- 同盟国が攻撃されたら支援を申し出る
- 経済格差が大きい場合に貿易交渉を提案

### 研究行動
- 進捗率: 研究値/100 × 1% per day
- 共同研究: 関係値60以上の研究者同士はボーナス+50%

### 秘密組織行動
- 行動: 情報収集・資金移動・他NPCへの働きかけ・政治工作
- 発覚リスク: 行動頻度が高いほど発覚確率が上昇
- 発覚時: 組織が危機状態になる
