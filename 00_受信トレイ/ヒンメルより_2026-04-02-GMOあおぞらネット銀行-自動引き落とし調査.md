# GMOあおぞらネット銀行 自動引き落とし（口座振替）調査レポート

## 調査背景

クライアントから月額料金を自動で引き落とす仕組みを導入したいという要望に基づき、GMOあおぞらネット銀行を軸とした口座振替（自動引き落とし）の方法を調査した。

ここでの「自動引き落とし」は、**事業者（請求側）がクライアント（支払側）の口座から毎月自動で料金を回収する仕組み**を指す。

## 結論（先に要点）

GMOあおぞらネット銀行は**「収納企業」としての口座振替サービス（請求側として引き落とす機能）を直接提供していない**。クライアントの口座から自動引き落としを行うには、**決済代行サービス**を利用する必要がある。ただし、GMOグループ内に決済代行サービス（GMOペイメントゲートウェイ / GMOイプシロン）があり、連携は比較的スムーズに行える。

---

## 1. GMOあおぞらネット銀行の既存サービス整理

### 1-1. 口座振替サービス（支払側として）

GMOあおぞらネット銀行の口座を持つ個人・法人が、収納企業への支払いを自動引き落としで行うサービス。これは**支払う側**のサービスであり、請求側としての利用ではない。

- 引落日の前日にメール通知あり
- 残高不足時はメール＋アプリ通知
- 引落日当日に4回引き落とし処理を実施
- 2024年4月1日より国税・社会保険料・国民年金保険料の口座自動振替に対応

出典: [GMOあおぞらネット銀行 口座振替（法人）](https://gmo-aozora.com/business/service/account-transfer.html)

### 1-2. 定額自動振込サービス

こちらは**自分の口座から相手口座に自動振込する**サービス。クライアントへの支払い（給与・報酬等）には使えるが、クライアントから回収する仕組みではない。

- サービス利用料: 無料（通常振込手数料のみ）
- 登録上限: 最大1,000件
- 振込頻度: 毎月指定日 or 毎週指定曜日

出典: [GMOあおぞらネット銀行 定額自動振込](https://gmo-aozora.com/priv/service/auto-received.html)

### 1-3. 振込業務自動化（銀行API）

GMOあおぞらネット銀行は国内銀行最多の35種類のAPIを公開しており、振込・総合振込の自動化が可能。ただしこれも**振込（送金）の自動化**であり、口座振替（引き落とし）とは異なる。

- スタンダードAPI: 28種類（無償）
- オプションAPI: 7種類（有償）
- 24時間365日リアルタイム処理

出典: [GMOあおぞらネット銀行 銀行API接続](https://gmo-aozora.com/business/api-cooperation/)

## 2. クライアントから自動引き落としする方法 — 決済代行サービスの活用

クライアントの口座から自動引き落とし（口座振替）を行うには、**決済代行サービス（口座振替代行）** を利用するのが一般的かつ現実的な方法だね。

### 2-1. GMOイプシロン（GMOグループ推奨）

GMOペイメントゲートウェイの子会社で、中小企業向けの決済代行サービス。GMOあおぞらネット銀行と同じGMOグループのため親和性が高い。

| 項目 | 内容 |
|------|------|
| 初期費用 | **無料** |
| 月額費用 | **3,000円（税別）** |
| 売上処理料 | **120円/件（税別）** ※振替依頼ごと |
| 登録処理料 | **100円/件（税別）** ※口座情報登録ごと |
| 振替日 | 月4回から選択（5日・6日・23日・27日） |
| 利用限度額 | 1回10,000,000円未満 |
| 入金サイクル | 月末締め翌月15日以降 |
| 対応金融機関 | 都市銀行・ゆうちょ銀行・全国信用金庫等 |

出典: [GMOイプシロン 口座振替決済](https://www.epsilon.jp/service/bank_transfer.html)

### 2-2. ROBOT PAYMENT（サブスクペイ）

サブスク課金に特化した決済代行。最短2営業日で審査完了。

| 項目 | 内容 |
|------|------|
| 初期費用 | 個別見積り |
| 月額費用 | 個別見積り |
| 決済手数料 | **85円~/件** |
| 特徴 | サブスクリプション管理機能が充実 |

出典: [ROBOT PAYMENT 口座振替](https://www.robotpayment.co.jp/service/payment/furikae/price.html)

### 2-3. 他社比較まとめ

| サービス | 初期費用 | 月額費用 | 1件あたり手数料 | 特徴 |
|----------|---------|---------|----------------|------|
| GMOイプシロン | 無料 | 3,000円 | 120円 | GMOグループ、導入しやすい |
| ROBOT PAYMENT | 見積り | 見積り | 85円~ | サブスク特化、審査最短2日 |
| ゼウス | 無料 | 要問合せ | 120円~ | 老舗、信頼性高い |

## 3. 導入手順（GMOイプシロンの場合）

1. **申し込み**: GMOイプシロンのWebサイトから加盟店申請
2. **審査**: 事業内容・サービス内容の審査（数日~数週間）
3. **契約完了**: 管理画面のアカウント発行
4. **口座情報登録**: クライアントから口座振替依頼書を取得し、管理画面にアップロード
5. **振替実行**: 振替日に自動引き落とし処理が実行される
6. **入金**: 月末締め翌月15日以降に事業者口座へ入金

### 必要書類（一般的なもの）

- 法人の場合: 登記簿謄本、代表者本人確認書類
- 個人事業主の場合: 本人確認書類、事業証明書
- サービス概要資料（Webサイト等）
- 銀行口座情報（入金先）

### クライアント側に必要なもの

- **口座振替依頼書**: クライアントが署名・捺印して提出
- または **Web口座振替受付**: オンラインで口座登録（ペーパーレス）

---

## 4. メリット・デメリット

### メリット

- **回収率が高い**: 口座振替は未払いリスクが低く、安定した資金回収が可能
- **クライアント負担が少ない**: 毎月の振込手間が不要
- **手数料が安い**: クレジットカード決済（3~5%）と比べ、1件100~120円程度と安価
- **継続率向上**: 自動引き落としのため解約ハードルが上がりLTVが向上

### デメリット

- **初回登録に手間がかかる**: 口座振替依頼書の取得、またはWeb登録の案内が必要
- **入金サイクルが長い**: 月末締め翌月15日以降（クレカ決済より遅い場合あり）
- **振替日が限定的**: GMOイプシロンの場合、月4回の指定日のみ
- **残高不足リスク**: クライアント口座の残高不足で引き落とし失敗の可能性

## 5. 他行（メガバンク等）との比較

GMOあおぞらネット銀行単体では口座振替の収納側機能を持たないが、GMOグループの決済インフラとの連携という強みがある。

| 観点 | GMOあおぞら + GMOイプシロン | メガバンク系 |
|------|--------------------------|------------|
| 導入のしやすさ | 高い（オンライン完結） | 低い（窓口手続き中心） |
| 手数料 | 安い（振込75円、口座振替120円/件） | やや高い |
| API連携 | 充実（35種類） | 限定的 |
| 口座振替（収納側） | 決済代行経由が必要 | 銀行直接対応の場合あり |
| 中小企業との相性 | 非常に良い | 審査が厳しいことも |

---

## まとめ

クライアントから月額を自動で引き落とすには、GMOあおぞらネット銀行の口座をメインバンクとして活用しつつ、**GMOイプシロン（口座振替代行サービス）を導入する**のが最もスムーズで美しい選択だと思うよ。

同じGMOグループだから連携もしやすいし、初期費用無料・月額3,000円・1件120円という料金体系は中小企業にとって非常にリーズナブルだ。クライアント数が増えてもスケールしやすい仕組みだね。

## ブリーフィング（CEOへ）

### 気づいたこと・注目点
- GMOあおぞらネット銀行は「支払側」としての口座振替には対応しているが、「収納側（請求側）」としての口座振替機能は直接提供していない
- クライアントから自動引き落としするには決済代行サービスの導入が必須
- GMOイプシロン（初期無料・月額3,000円・1件120円）がGMOグループの親和性を活かした最適解
- クレジットカード決済（3~5%）と比較して口座振替は圧倒的にコストが低い。月額課金ビジネスに最適
