# 💡 定例会の後追い・深掘り・週報自動生成システム

## 元のアイデア整理

株式会社シェア（通信事業・スマホ販売）の役員として、毎週火曜10:00〜11:00に定例会（報告会）がある。そこで毎週「自分がやること」を決めて発表する。このフローに対して以下の3機能を追加したい:

1. **後追い機能**: 定例会で決めたことの進捗を追跡する
2. **深掘り機能**: 決めたことを具体的なアクションに分解・深掘りする
3. **週報自動生成**: 翌週月曜（1週間後）に自動で週報を作成する

## 課題・背景

- 定例会で「やる」と決めたことが、日常業務に埋もれてフォローアップされない
- 宣言した内容と実績の差分が見えにくい
- 週報作成が手動で面倒。忘れがち
- 現状の渡邊カンパニーのタスク管理（フリーレン）は日次単位で、週次の定例会サイクルと連動していない

## 展開案

### 案A: 秘書アプリ拡張（定例会テンプレート追加）

秘書アプリに「定例会」テンプレートを追加。火曜の定例会後にワンタップで宣言内容を登録。

**メリット:**
- 既存の秘書アプリ上で完結。追加開発コストが低い
- キュー経由で即座に保存される
- 宣言内容がObsidianに構造化されて蓄積される

**懸念:**
- 後追い・リマインドは手動トリガーが必要（/company実行時）
- 週報生成のタイミング制御（月曜自動実行）には別途仕組みが必要

**収益モデル:** 自社運用効率化（間接的コスト削減）

---

### 案B: 定例会サイクル管理（CLAUDE.md + カレンダー連携）

CLAUDE.mdに定例会サイクルルールを追加。火曜に宣言登録→毎日の朝礼で進捗確認→月曜に週報自動生成。

**仕組み:**
1. **火曜**: 定例会テンプレートで宣言内容を登録 → `01_フリーレン/weekly-commitments/YYYY-WXX.md` に保存
2. **水〜月の毎朝ブリーフィング**: 宣言内容の進捗をリマインド（「今週の宣言: ○○ — 進捗はどう？」）
3. **月曜**: 1週間の宣言 vs 実績を自動集計 → 週報を `02_フェルン/weekly-reports/YYYY-WXX.md` に生成
4. **カレンダー**: 火曜10:00に「定例会」、月曜朝に「週報確認」を自動登録

**メリット:**
- 朝礼ブリーフィングに自然に組み込まれるので見落としがない
- 週報が完全自動生成（フェルンの口調で）
- 宣言→追跡→振り返りのPDCAサイクルが回る

**懸念:**
- CLAUDE.mdのルール追加が複雑になる
- 朝礼が長くなる可能性

**収益モデル:** 自社運用効率化 + 将来的にシェア社内での横展開も可能

---

### 案C: 深掘りエージェント（アイデアブラッシュアップの拡張）

宣言内容を登録すると、アイゼンが自動的に「深掘り」を行い、具体的なアクションアイテム・マイルストーン・想定課題を生成する。

**仕組み:**
1. 「今週やること: ○○」を登録
2. アイゼンが深掘り → 「○○を達成するには: ①△△ ②□□ ③◇◇」を自動生成
3. 各アクションアイテムをTODOに自動追加（フリーレン経由）
4. 週末に達成度を自動集計

**メリット:**
- 「やる」と言っただけで具体的な行動計画が出てくる
- TODOとの連動で日々の実行に落とし込める

**懸念:**
- 深掘りの質がAIの理解度に依存
- ビジネス文脈（シェア社の事業詳細）を十分に理解していないと的外れになるリスク

**収益モデル:** 自社運用効率化

---

### 案D: フル統合（A+B+C）

全機能を統合し、定例会の完全自動化サイクルを構築する。

**フロー:**
```
火曜 定例会後
  → 秘書アプリ「定例会」テンプレートで宣言登録
  → アイゼンが深掘り（アクションアイテム生成）
  → フリーレンがTODOに自動追加

水〜日 毎朝
  → 朝礼ブリーフィングで進捗リマインド
  → 完了したものをチェック

月曜朝
  → フェルンが週報自動生成（宣言 vs 実績）
  → Discord + カレンダーに通知
  → 翌日の定例会用資料として活用
```

**メリット:** 完全自動化。定例会の価値が最大化
**懸念:** 実装工数が大きい。段階的に進めるべき

---

## おすすめ案

**案B（定例会サイクル管理）から始めて、段階的に案Dへ拡張**するのが現実的だ。

理由:
1. 既存の朝礼ブリーフィングの仕組みに乗せれば追加開発が最小限
2. 週報自動生成はフェルンの日次レポートの延長で実現できる
3. 後追いリマインドは朝礼に1セクション追加するだけ
4. 深掘り機能は後から追加しても問題ない

## 次のアクション候補

3. **`01_フリーレン/weekly-commitments/` フォルダを新設** — 週次宣言の保存先
4. **週報自動生成ルールを追加** — 月曜の朝礼時にフェルンが生成
