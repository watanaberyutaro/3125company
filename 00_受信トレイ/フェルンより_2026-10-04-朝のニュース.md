### 1-1. Anthropic、Claude Codeに「Mods」を追加。TypeScriptで動作・画面・権限判断まで書き換え可能に
- **日付**：2026-10-01（米国時間）公開。Claude Code v2.1.287以降で既定で有効（第三者解説による）
- **要点**：
  - Modsは小さなTypeScriptの関数で、プロンプトがモデルに届く前の書き換え、ツール呼び出しのブロック・書き換え・再試行、権限リクエストの承認・拒否、ツール出力からの秘密情報の伏せ字化、画面要素の編集・置き換えができます。プラグインに入れて配布・導入します。CLIとデスクトップアプリで使えます。
  - 公式ブログは、Modsは「Claude Code本体と同じ権限でマシンにアクセスし、サンドボックス化されていない」と明記しており、信頼できる提供元のものだけを入れるよう求めています。
  - チーム・企業向けには、危険な動作を防ぐ組み込みMod「sec-default」が最初に読み込まれ、管理者は利用できるプラグインマーケットプレイスを制限できます。
  - 第三者の解説では、/diff画面やagents.mdの読み込みなど既存機能の一部がModsとして作り直されたと伝えられています（公式ブログ本文では未確認）。
- **出典**：[Claude公式ブログ「Customize Claude Code with mods in TypeScript」](https://claude.com/blog/claude-code-mods)／[CellCog（2026-10-02、公式ドキュメントの解説）](https://cellcog.ai/blog/claude-code-mods/)／[The New Stack](https://thenewstack.io/anthropic-claude-code-mods-plugins/)
- **事業への示唆**：受託開発・AI導入の現場で「顧客ごとの安全ルール（秘密情報の伏せ字化、本番環境への操作禁止など）をClaude Codeに組み込む」作業が、Modとして商品化できます。一方で、出所不明のModを入れることは野良ソフトを入れるのと同じです。社内では、導入してよいModの一覧と管理者設定を先に決めてください。
