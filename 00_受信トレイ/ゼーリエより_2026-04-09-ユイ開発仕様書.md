# 1. 要件定義

## 1-1. 目的・背景

「ソードアート・オンライン」に登場するAI「ユイ」をモデルとした、実用的なパーソナルAIコンパニオンを構築する。

ユーザー（カメレオン）がAndroidスマートフォンに向かって「ユイ」と話しかけるだけで起動し、音声で自然に対話できる常時待機型のパーソナルAIとして機能させる。

**v3 設計方針（v2からの変更点）:**

| 変更点 | v2（旧） | v3（新） |
|--------|---------|---------|
| フロントエンド | Python CLIスクリプト（Mac/Raspberry Pi） | Androidアプリ（Flutter） |
| ウェイクワード | SpeechRecognition / pocketsphinx | Porcupine（高精度オンデバイス） |
| STT | Whisper / Google Cloud STT | Android標準 Speech Recognition（オンデバイス） |
| LLM実行場所 | ローカルPC / Raspberry Pi | Windows PC（常時起動） |
| 通信経路 | ローカル or Obsidian iCloud同期 | Cloudflare Tunnel（固定URL・無料） |
| TTS | pyttsx3 / gTTS | Android標準TTS |
| メモリ | Obsidian Vault（iCloud同期） | ローカルファイル `~/yui/memory/`（Git push） |
| コスト | claude CLIサブスク | 同左（変更なし） |

**全コスト無料を維持する:**
- Porcupine: 無料枠（1デバイス）
- Cloudflare Tunnel: 無料プラン
- Android Speech Recognition / TTS: OS標準
- Git: 無料

| 項目 | 内容 |

**概要:** AndroidからのSTT結果を受信し、claude -p で推論してレスポンスを返す。

## 2-5. claude -p 呼び出しコード（Python asyncio）

```python
# claude_runner.py
import asyncio
import subprocess
from pathlib import Path

CLAUDE_MD_PATH = Path("~/yui/server/CLAUDE.md").expanduser()


async def call_claude(prompt: str, timeout: int = 30) -> str:
    """
    claude -p をサブプロセスで非同期実行する。
    プロンプトをstdinで渡し、stdoutからレスポンスを取得する。
    """
    process = await asyncio.create_subprocess_exec(
        "claude", "-p", prompt,
        stdout=asyncio.subprocess.PIPE,
        stderr=asyncio.subprocess.PIPE,
    )

    try:
        stdout, stderr = await asyncio.wait_for(
            process.communicate(),
            timeout=timeout
        )
    except asyncio.TimeoutError:
        process.kill()
        raise RuntimeError(f"claude -p timed out after {timeout}s")

    if process.returncode != 0:
        raise RuntimeError(f"claude -p failed: {stderr.decode()}")

    return stdout.decode().strip()
```

**プロンプト組み立て（prompt_builder.py）:**

```python
# prompt_builder.py
from pathlib import Path

MEMORY_DIR = Path("~/yui/memory").expanduser()
CLAUDE_MD   = Path("~/yui/server/CLAUDE.md").expanduser()


def build_prompt(user_text: str, session_id: str) -> str:
    character   = CLAUDE_MD.read_text(encoding="utf-8")
    summary     = _read_or_empty(MEMORY_DIR / "summary.md")
    important   = _read_or_empty(MEMORY_DIR / "important.md")
    session_log = _read_or_empty(MEMORY_DIR / "sessions" / f"{session_id}.md")

    return f"""{character}

## 長期記憶
{summary}

## 重要事項
{important}

## 今日の会話履歴
{session_log}

## ユーザーの発話
{user_text}
"""


def _read_or_empty(path: Path) -> str:
    return path.read_text(encoding="utf-8") if path.exists() else "（なし）"
```

### Gitバックアップ

```python
# memory_manager.py（抜粋）
import subprocess

def git_push_memory() -> None:
    """セッション終了後に memory/ を Git push する"""
    yui_dir = Path("~/yui").expanduser()
    commands = [
        ["git", "add", "memory/"],
        ["git", "commit", "-m", f"memory: session {datetime.now().strftime('%Y-%m-%d %H:%M')}"],
        ["git", "push"],
    ]
    for cmd in commands:
        result = subprocess.run(cmd, cwd=yui_dir, capture_output=True)
        if result.returncode != 0:
            # push失敗はログ記録のみ（致命的エラーとしない）
            print(f"[git] warning: {result.stderr.decode()}")
```

### 3. ~/yui/server/claude_runner.py

```python
import asyncio
from pathlib import Path

async def call_claude(prompt: str, timeout: int = 30) -> str:
    process = await asyncio.create_subprocess_exec(
        "claude", "-p", prompt,
        stdout=asyncio.subprocess.PIPE,
        stderr=asyncio.subprocess.PIPE,
    )
    try:
        stdout, stderr = await asyncio.wait_for(
            process.communicate(), timeout=timeout
        )
    except asyncio.TimeoutError:
        process.kill()
        raise RuntimeError(f"claude -p timed out after {timeout}s")
    if process.returncode != 0:
        raise RuntimeError(f"claude -p failed: {stderr.decode()}")
    return stdout.decode().strip()
```
