# 1. 要件定義

## 1-1. 目的・背景

「ソードアート・オンライン」に登場するAI「ユイ」をモデルとした、実用的なパーソナルAIコンパニオンを構築する。

ユーザー（カメレオン）がスマートフォンに向かって「ユイ」と話しかけるだけで起動し、音声で自然に対話できる常時待機型のパーソナルAIとして機能させる。

**設計方針:**

| 項目 | 内容 |
|------|------|
| フロントエンド | スマホアプリ（Flutter・Android/iOS両対応） |
| ウェイクワード検出 | Porcupine（オンデバイス・高精度） |
| STT | Android / iOS OS標準 Speech Recognition |
| TTS | Android / iOS OS標準 TTS |
| LLM実行場所 | MacBook（Phase 1） / Windows PC（Phase 2） |
| LLM呼び出し方法 | `claude -p` CLI をサブプロセス実行（無料） |
| 通信経路 | Cloudflare Tunnel（固定URL・無料） |
| メモリ | ローカルファイル `~/yui/memory/`（Obsidian Vaultと完全分離） |
| コスト | 全コスト無料 |

**コスト内訳（全て無料）:**

- Porcupine: 無料枠（1デバイス）
- Cloudflare Tunnel: 無料プラン
- Android / iOS Speech Recognition / TTS: OS標準
- `claude -p` CLI: Claude Proサブスク内（追加費用なし）
- Git: 無料

| 項目 | 内容 |
|------|------|
| ユーザー | カメレオン（本システムオーナー）一名のみ |

## 2-5. claude -p 呼び出しコード（Python）

```python
import asyncio
import subprocess
from pathlib import Path

MEMORY_DIR = Path.home() / "yui" / "memory"
CLAUDE_MD = Path.home() / "yui" / "CLAUDE.md"

async def call_claude(user_text: str, session_id: str) -> str:
    # メモリ読み込み
    summary = (MEMORY_DIR / "summary.md").read_text(encoding="utf-8") if (MEMORY_DIR / "summary.md").exists() else ""
    important = (MEMORY_DIR / "important.md").read_text(encoding="utf-8") if (MEMORY_DIR / "important.md").exists() else ""

    # 当日セッションログ読み込み
    session_files = sorted(MEMORY_DIR.glob(f"sessions/{session_id}-*.md"))
    session_log = ""
    for f in session_files:
        session_log += f.read_text(encoding="utf-8") + "\n"

    # CLAUDE.mdテンプレート読み込み・変数注入
    template = CLAUDE_MD.read_text(encoding="utf-8")
    prompt = (
        template
        .replace("{summary.md の内容}", summary)
        .replace("{important.md の内容}", important)
        .replace("{当日セッションログ}", session_log)
        .replace("{STTで取得したテキスト}", user_text)
    )

    # claude -p サブプロセス実行
    proc = await asyncio.create_subprocess_exec(
        "claude", "-p", prompt,
        stdout=asyncio.subprocess.PIPE,
        stderr=asyncio.subprocess.PIPE,
    )
    stdout, stderr = await asyncio.wait_for(proc.communicate(), timeout=60.0)

    if proc.returncode != 0:
        raise RuntimeError(f"claude -p failed: {stderr.decode()}")

    return stdout.decode().strip()
```

**ポイント:**
- `claude -p` は標準入力ではなく引数でプロンプトを渡す
- タイムアウト60秒（LLM応答が遅い場合のフェイルセーフ）
- `asyncio.create_subprocess_exec` でノンブロッキング実行

```python
import git

def backup_memory():
    repo = git.Repo(Path.home() / "yui")
    repo.git.add(A=True)
    repo.index.commit(f"yui memory backup: {datetime.now().isoformat()}")
    repo.remotes.origin.push()
```

## 2-8. Cloudflare Tunnel セットアップ手順

### MacBook（Phase 1）

```bash
# 1. cloudflared インストール（Homebrew）
brew install cloudflared

# 2. Cloudflareアカウントへログイン
cloudflared tunnel login

# 3. Tunnelを作成
cloudflared tunnel create yui-tunnel

# 4. 設定ファイル作成
# ~/.cloudflared/config.yml
url: http://localhost:8000
tunnel: <TUNNEL_ID>
credentials-file: ~/.cloudflared/<TUNNEL_ID>.json

# 5. DNSルーティング設定（Cloudflareで管理するドメインが必要）
cloudflared tunnel route dns yui-tunnel yui.yourdomain.com

# 6. Tunnel起動
cloudflared tunnel run yui-tunnel

# または launchd で自動起動
cloudflared service install
```

**無料ドメインが使えない場合の代替:**
Cloudflare Zero Trust の Quick Tunnels（`cloudflared tunnel --url http://localhost:8000`）でも動作するが、URLが起動ごとに変わるためFlutterアプリ側の設定変更が必要。本番運用にはカスタムドメイン推奨。

### Phase 2（Windows PC）への移行

```
1. Windows PCに cloudflared インストール（winget install Cloudflare.cloudflared）
2. 同じTunnel IDの credentials ファイルを Windows PCへコピー
3. cloudflared service install で Windows サービスとして登録
4. FastAPIサーバー（main.py）を Windows PC 上で起動
5. FlutterアプリのAPIエンドポイントURLは変更不要（CloudflareTunnelのURLは同一）
```

**移行時の確認事項:**

| 確認項目 | 内容 |
|---------|------|
| `claude` CLI | Windows PCにインストール済み・`claude -p` 動作確認 |

```

- `claude` CLIがPATHに存在し、`claude -p "テスト"` が動作すること

## ディレクトリ構成
以下を ~/yui/ に作成すること:

~/yui/
├── CLAUDE.md               ← 別途配置済み（実装不要）

├── memory_manager.py       ← 実装対象

└── memory/
    ├── summary.md          ← 空ファイルで初期化

## main.py の仕様

### エンドポイント

#### POST /chat
リクエスト:
{
  "text": "string",         // STTで取得した発話テキスト（必須・空文字不可）
  "session_id": "string"    // YYYY-MM-DD形式（省略時は当日日付）
}

正常レスポンス:
{
  "text": "string",         // ユイの返答テキスト
  "session_file": "string"  // 保存したセッションファイルパス
}

エラーレスポンス:
{
  "error": "string"
}

#### GET /health
レスポンス: {"status": "ok"}

### 処理フロー（POST /chat）

1. memory/summary.md, memory/important.md を読み込む（存在しない場合は空文字）
2. memory/sessions/{session_id}-*.md を日付順に読み込み、当日の会話ログを結合する
3. ~/yui/CLAUDE.md のテンプレートを読み込み、以下の変数を置換する:
   - {summary.md の内容} → summary.md の内容
   - {important.md の内容} → important.md の内容
   - {当日セッションログ} → 当日セッションログ
   - {STTで取得したテキスト} → リクエストの text フィールド
4. asyncio.create_subprocess_exec で `claude -p "{プロンプト}"` を実行する
   - タイムアウト: 60秒
   - returncode != 0 の場合は RuntimeError を raise
5. 返答テキストを以下の形式で sessions/ に追記保存する:
   ファイル名: {session_id}-{NNN}.md（NNNは当日連番001〜。既存ファイルの次の番号）
   内容:
   ## {YYYY-MM-DD HH:MM:SS}
   **パパ:** {発話テキスト}
   **ユイ:** {返答テキスト}
6. テキストに「覚えておいて」が含まれる場合、memory/important.md に追記する:
   [YYYY-MM-DD HH:MM:SS] {発話テキスト}
7. レスポンスを返却する

### 起動コマンド
uvicorn main:app --host 0.0.0.0 --port 8000

### 注意事項
- Claude APIパッケージ（anthropic）は使用しない
- `claude -p` CLIのみを使用する
- asyncio.create_subprocess_exec を使用してノンブロッキングで実行する
- プロンプトに含まれるダブルクォートはエスケープ処理すること
- CORSはすべてのオリジンを許可する（FastAPIのCORSMiddleware使用）
```

```
- 中央に現在の状態を表示するテキスト
- 状態に応じたアイコンまたはアニメーション
- 設定ボタン（右上）→ サーバーURL入力ダイアログ
- サーバーURLはSharedPreferencesで保存する

## 処理フロー

1. アプリ起動時にPorcupineを初期化する
   - キーワードファイル: assets/yui_keyword.ppn
   - アクセスキー: 設定画面から入力・SharedPreferencesで保存
   - sensitivity: 0.5

2. idle状態でPorcupineがウェイクワード「ユイ」を検出したら:
   - TTS「はい、なんですか？」を再生する
   - 状態をlisteningに変更する
   - STTを開始する（言語: ja-JP）

3. STT完了後（onResult）:
   - 状態をprocessingに変更する
   - POST {serverUrl}/chat にリクエストを送信する:
     {"text": "{認識テキスト}", "session_id": "{YYYY-MM-DD}"}
   - タイムアウト: 90秒

4. レスポンス受信後:
   - 状態をspeakingに変更する
   - TTS で response["text"] を読み上げる
   - 読み上げ完了後、状態をidleに変更してPorcupine待機へ戻る

5. エラー時:
   - 状態をerrorに変更する
   - TTSで「ごめんなさい、エラーが発生しました」を再生する
   - 3秒後にidleへ戻る
```
