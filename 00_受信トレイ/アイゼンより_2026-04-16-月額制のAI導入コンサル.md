# 月額制のAI導入コンサル

---

## 元のアイデア整理

既存のスポット型AI導入支援を、月額定額のサブスクリプションモデルに転換する。
単発で終わりがちなコンサルを「継続関係」に昇華させることで、顧客にとっての安心感と、渡邊カンパニーにとっての安定収益を同時に得る発想だ。

---

## 課題・背景

**なぜ今このアイデアが有効か**

- AI導入の失敗率は高い。「とりあえず入れた」で終わる企業が多く、伴走型支援への需要が拡大している
- スポット型コンサルは案件単価が高くても売上が不安定。営業コストも毎回かかる
- 中小企業はAI人材を抱えられない。外部の専門家を「社内のAI担当」として月額で持ちたいニーズがある
- ChatGPT・Claudeの普及で「AIを使いたいが何から始めればいいかわからない」企業が急増している
- 渡邊カンパニーはAI導入支援・システム開発・スマホショップコンサルの実績を持つ。AI×業務改善の知見が強い

---

## 展開案

### 案A — ライトプラン（入門層向け）
**月額 3〜5万円**

| 内容 | 詳細 |
|------|------|
| 月次オンラインMTG | 1回60分（AI活用相談・進捗確認） |
| Slackサポート | 平日テキスト質問（回答は48h以内） |
| ツール選定アドバイス | ChatGPT, Notion AI, 各種SaaS選定補助 |
| 月次レポート | 活用状況と次月アクションのまとめ |

**ターゲット**: 従業員5〜20名の中小企業・個人事業主（初めてAIを導入したい層）

**メリット**: 参入障壁が低い。顧客獲得しやすい
**懸念**: 単価が低く、1人あたりの工数が重くなりすぎると赤字になるリスクがある

---

### 案B — スタンダードプラン（メイン層向け）
**月額 10〜20万円**

| 内容 | 詳細 |
|------|------|
| 月次オンサイト or オンラインMTG | 2回/月（各90分） |
| AI業務改善提案 | 毎月1業務フロー分析・改善提案 |
| プロンプト設計・テンプレート提供 | 社内で使えるプロンプトのカスタマイズ |
| Slackサポート | 平日テキスト質問（24h以内） |
| 社員向けAI研修 | 四半期に1回（2h、オンライン可） |
| 月次レポート | KPI進捗・導入効果の可視化 |

**ターゲット**: 従業員20〜100名の中堅中小企業。DX推進担当者がいないが取り組みたい企業

**メリット**: 十分な利益率を確保しながら、顧客にとっての体感価値も高い。スマホショップコンサルの横展開にも使える
**懸念**: 月次MTGの準備・移動コストが積み重なる。スケールには人員が必要

---

### 案C — プレミアムプラン（DX推進層向け）
**月額 30〜50万円**

| 内容 | 詳細 |
|------|------|
| 専任コンサルタントアサイン | 窓口担当者を固定 |
| 週次MTG | 1回/週（30〜60分） |
| AI実装・PoC支援 | 小規模自動化スクリプト・API連携を含む |
| 社員研修 | 月1回（カスタマイズ内容） |
| AI活用ロードマップ作成 | 初月に6ヶ月ロードマップを策定 |
| 経営報告 | 四半期に1回・経営層向け進捗報告 |

**ターゲット**: 製造・流通・医療・小売など業務が複雑な中規模企業

**メリット**: 高単価。開発部門との連携でアップセル機会も多い
**懸念**: 工数負荷が高い。専任コンサル人材の確保が前提

---

### 案D — スマホショップ特化プラン（既存事業との連携）
**月額 5〜15万円**

スマホショップコンサル事業の既存顧客に対して、AI活用（接客支援・在庫分析・シフト最適化・マニュアル自動生成など）に絞ったサブスク支援を提供する。

**メリット**: 既存の信頼関係があるため営業コストがほぼゼロ。導入事例が積み上がりやすく、横展開ができる
**懸念**: マーケットが限定的。スマホショップ業界以外に転用しにくい

---

### 案E — 成果連動型（ハイブリッドモデル）
**月額基本料 5〜10万円 + 成果フィー**

基本サポートを低価格で提供し、業務効率化・コスト削減が数値で確認できた場合に成果フィーを追加請求するモデル。

**メリット**: 顧客にとってリスクが低く導入しやすい。渡邊カンパニー側の信頼証明になる
**懸念**: 成果の測定方法・定義を事前に合意しておかないとトラブルになる。経理処理が複雑になる

---

## おすすめ案

**まずは案B（スタンダードプラン）を軸に、案Dで初期顧客を獲得するのが現実的だ。**

理由を整理する。

1. **スタンダードプランは収益モデルとして成立しやすい** — 月15万×10社で月商150万。人件費・運営コストを引いても利益が出る水準だ
2. **スマホショップ顧客は既にいる** — 案Dで既存顧客に横展開すれば、初期0から営業を始める必要がない。導入事例も作れる
3. **3プラン体制（ライト/スタンダード/プレミアム）を名目上は用意して、実態はスタンダードに集中する** — 見た目の選択肢は顧客の安心感につながる

---

## 収益モデル試算

### スタンダードプラン（月額15万）での試算

| 指標 | 値 |
|------|-----|
| 月額単価 | 15万円 |
| 目標契約数（初年度末） | 10社 |
| 月間売上（10社時点） | 150万円 |
| 年間売上（10社定着時） | 1,800万円 |
| 推定LTV（平均契約期間24ヶ月） | 360万円/社 |
| 推定解約率（目標） | 月5%以下 |
| CAC（顧客獲得コスト想定） | 30〜50万円/社 |
| CAC回収期間 | 2〜4ヶ月 |

**月次工数試算（1社あたり）**

- MTG準備・実施: 4〜6時間/月
- レポート作成: 2〜3時間/月
- Slackサポート: 2〜4時間/月
- 合計: 約8〜13時間/月

10社で80〜130時間/月。1人で対応できる上限は約5〜6社。**7社以上になったらサポートスタッフが必要**になる。

## MVP（最小構成）— 最初に何から始めるか

**Phase 1（今すぐできる）**

1. **既存のスマホショップコンサル顧客1〜2社に声をかける**
   - 「AIの使い方を月額で支援するプランを試験的に始める」と話す
   - 初期3ヶ月は半額モニター価格（5〜7万）で提供し、事例化する
2. **サービス内容・料金を1枚の提案書にまとめる**
   - プラン表・サポート内容・導入ステップの3点だけあれば十分
3. **Slackワークスペースを顧客用に1つ立ち上げる**
   - 有料ツール不要。無料プランで始められる

**Phase 2（事例ができたら）**

4. LP（ランディングページ）を作成し、問い合わせ導線を作る
5. SNS（LinkedInまたはX）でAI活用事例を発信し始める
6. 新規リード獲得を営業部門と連携して開始

## リスク・課題

| リスク | 内容 | 対策 |
|--------|------|------|
| 人的リソース不足 | 契約数が増えると1人では回せなくなる | 最初から「6社以上は採用」のラインを決めておく |
| 解約率の高さ | AI導入の効果が出ないと解約される | 月次レポートで小さな成果を可視化し続ける。3ヶ月で1つ「成果事例」を作ることを目標にする |
| 差別化の難しさ | 大手コンサル・SaaSベンダーも同様サービスを展開し始めている | 渡邊カンパニーの強みは「スマホ業界の実務知識 × AI」の掛け合わせ。業界特化で戦う |
| 料金設定の迷い | 安すぎると赤字、高すぎると売れない | まずモニター価格で始め、事例と実工数を計測してから本番価格に移行する |
| スコープクリープ | 顧客が「これもやってくれ」と範囲を広げてくる | 契約前に「何が含まれて何が含まれないか」を明文化する。追加は別途見積もりを徹底する |

## 🔍 ブリーフィング（CEOへ）

### 気づいたこと・注目点

- 既存のスマホショップコンサル顧客を起点にすれば、営業コストゼロで初期顧客を獲得できる可能性がある。これが最大の優位性だ
- 月額15万×10社で年商1,800万。人件費を差し引いても事業として成立する水準。現実的な目標値だ
- 解約率コントロールが生命線。「成果の見える化」を月次で続けられるかどうかが全てを決める
- スコープクリープは必ず起きる。契約書の設計を最初から丁寧にやっておくべきだ
- 大手との差別化は「業界特化」一択。スマホ業界 × AI という組み合わせは今のところ希少だ
